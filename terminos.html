Condiciones del Servicio

Última actualización: octubre 2026

Estas condiciones aplican al uso de los sistemas de automatización y asistentes construidos por LE CODE ONE para sus clientes, incluyendo el acceso a herramientas de calendario (Google Calendar) usadas para agendar citas.

1. Descripción del servicio

LE CODE ONE desarrolla sistemas de automatización con inteligencia artificial para negocios, incluyendo asistentes de atención por WhatsApp y herramientas de gestión de citas conectadas a Google Calendar.

2. Uso del servicio

El servicio se usa para gestionar citas, consultas y atención al cliente en nombre del negocio que lo contrata. El acceso a Google Calendar se limita estrictamente a consultar disponibilidad y crear o modificar eventos de citas del negocio correspondiente.

3. Responsabilidad

LE CODE ONE pone razonable cuidado en el funcionamiento de sus sistemas, pero no garantiza disponibilidad ininterrumpida. Cualquier error o interrupción se corrige en el menor tiempo posible.

4. Datos y privacidad

El tratamiento de datos personales se rige por nuestra Política de Privacidad.

5. Cambios a estas condiciones

Podemos actualizar estas condiciones ocasionalmente. Publicaremos cualquier cambio en esta misma página.

6. Contacto

Si tienes preguntas sobre estas condiciones, contáctanos a través de nuestros canales oficiales de atención.
